# 📩 AI Spam Message Classifier

This is a simple Machine Learning project that detects whether a message is SPAM or NOT SPAM.

## 🚀 Live Demo
(Your Hugging Face Space link will go here)

## 🧠 How it works
- The model is trained using labeled SMS data
- Text is converted into numerical features using TF-IDF / Count Vectorizer
- A Naive Bayes classifier is used for prediction

## 📦 Tech Stack
- Python
- Scikit-learn
- Gradio
- Pandas
- NumPy

## 📊 Model Type
- Multinomial Naive Bayes (NLP Classification)

## 🎯 Features
- Real-time message prediction
- Simple web UI
- Lightweight ML model
